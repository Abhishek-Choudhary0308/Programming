JAVA PRACTICAL INTERVIEW SOLUTIONS
=================================

Source: "Most Frequently asked Practical questions.docx"
Contains 30 standalone Java classes, one class per problem.

Requirements:
- Java 8+ for the solutions; examples use standard Java APIs.
- Compile all:
    javac *.java

- Run an individual problem:
    java Problem01_FirstNonRepeatingCharacter

Problem mapping:
01 First Non-Repeating Character (loop + Java 8 Stream)
02 Group Anagrams
03 Separate Even and Odd Numbers (Streams + two threads)
04 Second Highest Number
05 Thread-Safe Singleton (Double-Checked Locking)
06 Find Duplicate Elements (Stream solution)
07 Longest Substring Without Repeating Characters
08 Word/Character Frequency Count
09 Maximum Subarray Sum (Kadane)
10 Reverse Words in a Sentence
11 Employee Grouping and Aggregations
12 Move All Zeros to One End
13 Reverse Letters Only
14 Custom Immutable Class
15 Maximum Product Subarray
16 Product of Array Except Self
17 Two Sum
18 Stack Using Queues
19 Reverse Singly Linked List (iterative + recursive)
20 Valid Parentheses
21 String Rotation Check
22 Find Missing Number
23 Rotate an Array
24 Minimum Size Subarray Sum
25 Dutch National Flag (0,1,2)
26 Next Greater Element
27 Merge Two Sorted Arrays Without Third Array
28 Transaction Aggregation / Summarization
29 Producer-Consumer
30 Detect Cycle in Linked List (Floyd)

Each .java file has its own public class and can be compiled/run independently.
